## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` from the repository root to `$MAKEFUN_OUTPUT_DIR/entry.png`. The image is 1024 by 1024 pixels, a PNG under 1 MiB, and the program writes the same bytes on every run.
